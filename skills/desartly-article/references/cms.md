# Article API workflow

Studio: https://studio.desartly.info ; MCP: https://studio.desartly.info/mcp . Prefer connected/discoverable `cms_*` tools, then existing private scoped environment credentials, then an already authenticated same-origin Studio session if documented browser capabilities support it. Verify one read-only `cms_schema` call before declaring access missing. Missing MCP tools alone are not proof of missing CMS access. Do not print secrets, export whole browser profiles, mint credentials or place credentials in this skill. A skill cannot transfer a login across devices/chats.

Use `cms_list {kind:"article",query:...}` and `cms_get {kind:"article",id}` to avoid duplicates and back up only the document being edited. Read live schema and `cms_editorial_standard`; project-specific editorial rules are not article constraints. Current article fields include title, id, blocks, excerpt, category, date, author, language, tags, relatedProject, coverImage, heroImage, references and announcement. Check live support rather than treating this list as authoritative. Copy valid language enum values from live schema/existing articles or the editor; never guess a value from a UI label. The main article may be Persian or English, while private captions include both languages.

Use native editable text/markdown and image blocks with unique IDs. Reuse returned media URLs. Resolve a supplied library folder precisely and inspect only its relevant assets; never assume a folder name is the article ID. For new files use descriptive lowercase kebab-case names, correct alt text and the allowed article media folder from live architecture. Optimize raster images before API upload when server transformations are unavailable. Read bytes in a script so base64 stays out of model context and logs.

Create a new draft via `cms_create {kind:"article",document}`. Save a merged document via `cms_save {kind:"article",id,version,document}` preserving unrelated fields and `announcement.notes`. Captions are strings: `announcement:{fa:"…",en:"…",hashtags:"#Design\n#Typography"}`. They remain CMS-only; do not insert them in public article blocks.

Run `cms_review {kind:"article",id}` and address meaningful findings. Current checks include supporting images, related project and source references; do not invent a project relationship, sources or filler images to obtain 100%. Explain legitimately inapplicable checks. Empty sections and missing captions are actionable. Score alone does not prove factual accuracy, prose quality or visual quality.

Read the saved article to verify content, primary language and all three nonempty announcement fields. Inspect the actual Studio preview and, when publishing, responsive page. For explicit publication use fresh `cms_get` then `cms_publish {kind:"article",id,version}`; verify the actual returned/rendered public link without guessing its route. On conflicts reread and merge only intended changes. After a timed-out write, inspect state before retrying; never blindly recreate a draft. No whole-site publishing, app deployment, social distribution or unrelated document edits.
