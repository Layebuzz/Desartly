# Choose one discipline

Use live `cms_project_template` as a schema starting point, not a mandate to leave all its blocks. Read only the matching section below. Hybrid projects may borrow relevant evidence from a second section while retaining one CMS discipline.

## Product — UI/UX, digital services, dashboards, apps

Ground the case in the primary task, user context and constraints. Explain the information hierarchy, key flow, interaction states and responsive choices with working UI evidence. Include research, testing, journey maps or wireframes only if supplied or actually performed; a retrospectively drawn wireframe must be described as a structure explanation, not discovery evidence.

Useful sequence: task/context → working overview → one consequential decision → isolated live components → responsive flow → delivered scope and limits. Product personality describes intended brand expression, not usability validation.

HTML blocks should be self-contained, sandbox-compatible and below the current document-size limit. Upload assets to storage and use returned URLs. Avoid remote scripts, large base64 blobs, fixed-width crops and scroll hijacking. Keep native narrative outside the embed. Isolate components with `componentSelector` while preserving required state/scripts; use `previewWidth:390` for a real responsive demonstration rather than scaling down a desktop screen. Supply a `staticImage` only as PDF/export fallback.

Check main controls and state changes; verify selectors actually select visible content. In narrow cards, weather hours, units, labels and icons must wrap intentionally without clipping. Check nested grids for `min-width`, overflow and long labels. Distinguish meaningful intentional whitespace from empty/broken sections. Inspect all embeds in the final page, not only the source HTML. No static image substitution to conceal a broken layout.

## Branding — identity, packaging, brand systems

Explain the brand context, intended audience, central idea and how that idea controls the identity. Show the real wordmark/logo, type, palette, graphic devices, hierarchy, packaging variants and applications that exist in the folder. Describe visible construction and use rules rather than inventing market research or consumer response.

Useful sequence: identity reveal → tension/context → central idea → system details → applications at different scales → delivered system and limits. Packaging warrants variant differentiation, label hierarchy, material/finish intent and practical legibility where visible. Do not assert print tests, regulatory compliance or manufacturing suitability from a mockup. Identify mockups and mood references honestly; distinguish final artwork from inspiration once without cluttering every caption.

Use separate, editable image assets and concise native text. Alternate hero views, identity details and in-context applications. Preserve critical logo clear space and label readability. Keep client and agency/intermediary credits distinct. Do not force a UI prototype or fake motion into an identity project.

## Communication Design — advertising, campaigns, editorial, motion, visual communication

State the communication problem, intended audience, central proposition and relationship between message and visual execution. Show the supplied key visual, copy hierarchy, channel adaptation, sequence or motion behavior. A campaign shown on mockups does not prove a media buy or public rollout.

Useful sequence: strongest execution → audience tension → campaign idea → execution anatomy → actual channel variations or motion → delivered scope and supported results. Explain how composition changes between formats rather than merely listing deliverables. For editorial/information design, show reading order and navigation. For motion, show timing, transitions and storyboard only where actual material supports them.

Do not invent impressions, engagement, locations, client acceptance or awards. Preserve pitch status and commissioning details. Use moving assets or self-contained interaction when available and supported; otherwise show truthful frames or a storyboard. Never fabricate an autoplay performance claim. If performance evidence exists, report its method and limits beside the result.

## Other and mixed work

Map illustration, photography, exhibition, environmental, service or other design work to the nearest **existing discipline based on deliverables**, while describing its specific scope in text. If no mapping is defensible, ask before classifying; do not invent a fourth discipline or an industry. Apply the same evidence and visual-rhythm principles without forcing research, UI, packaging or campaign sections that do not exist.
