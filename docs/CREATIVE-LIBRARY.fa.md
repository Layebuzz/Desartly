# بانک ایده — راهنمای استفاده و نگهداری

مسیر: CMS → Creative library، آدرس `/studio/ideas`.

اکسل اولیه شش تب و ۲٬۶۷۷ کارت دارد. Creative Matrix از ۷۵۰ ردیف، سه کارت مستقل برای Branding، Communication design و Digital product می‌سازد؛ سلول‌های ادغام‌شدهٔ صنعت، شخصیت و صفت از ردیف قبل خوانده می‌شوند. پنج تب دیگر ۴۲۷ کارت مرجع دارند. ردیف ۱۰۱ در Platform& Awards، identitydesigned، در منبع فقط نام دارد؛ اطلاعاتی برای آن اختراع نشده است.

جست‌وجو و فیلترهای صنعت، شخصیت، نوع پروژه و وضعیت تیک در Creative Matrix موجودند. تیک به معنی انتخاب شخصی است و امتیاز مارکتینگ یا انتشار پروژه ایجاد نمی‌کند. دسته‌های اکسل مستقل از taxonomy قفل‌شدهٔ پروژه‌ها هستند.

برای توسعه: Import Excel → انتخاب `.xlsx` → بررسی شمار کارت‌های هر تب → Merge یا Replace → Import cards. فایل جدید ویرایش داده است و به deploy نیاز ندارد. در Creative Matrix همان نام تب و ترتیب هشت ستونِ فایل اولیه را حفظ کنید؛ برای تب‌های مرجع ردیف اول، عنوان ستون‌ها باشد. فرمول‌ها اجرا نمی‌شوند؛ مقدار cached اکسل خوانده می‌شود. نام جدید تب، مجموعهٔ مرجع جدید می‌سازد.

Merge، کارت‌های قبلی را نگه می‌دارد و کارت هم‌شناسه را به‌روزرسانی می‌کند. Replace فقط کارت‌های فایل تازه را نمایش می‌دهد. شناسهٔ ایده از نام تب، صنعت، شخصیت، صفت، شمارهٔ ایده و نوع پروژه ساخته می‌شود؛ تغییر متن ایده تیک را پاک نمی‌کند، ولی تغییر این هویت یک کارت تازه می‌سازد. شناسهٔ مرجع از نام تب و عنوان آن ساخته می‌شود.

محدودیت‌ها: فایل فشرده تا ۱۰ MB، محتوای استخراج‌شده تا ۴۰ MB، ۳۰ تب و ۱۰٬۰۰۰ کارت. بانک و تیک‌ها در چهار جدول مستقل D1 ذخیره می‌شوند؛ در portfolio_state یا bundle عمومی نیستند. API مالک: GET `/api/ideas` و POST `/api/ideas/begin`، `/batch`، `/commit` و `/check`. همهٔ تغییرها احراز هویت و کنترل Origin دارند. ارسال در دسته‌های ۶۰ کارت انجام می‌شود؛ خطای انتقال بانک فعال را عوض نمی‌کند. دو import هم‌زمان اجازهٔ بازنویسی نتیجهٔ یکدیگر ندارند.

نسخه‌های قبلی در دیتابیس نگهداری می‌شوند؛ UI بازیابی نسخه هنوز عرضه نشده است. بکاپ کامل دیتابیس باید چهار جدول idea_versions، idea_cards، idea_state و idea_checks را هم شامل شود. در توسعهٔ محلی این بخش با Wrangler و D1 محلی آزموده می‌شود؛ Viteِ دارای LocalStore بدون D1 پیام نیاز به دیتابیس ابری می‌دهد.

اعتبارسنجی: ۲۶۱ تست موفق، build موفق؛ parser واقعی همین اکسل شش تب و ۲٬۶۷۷ کارت را تولید کرد؛ حفظ context سلول‌های ادغام‌شده تأیید شد. رابط محلی در دسکتاپ و عرض ۳۹۰ بررسی شد، فیلتر ترکیبی Automotive/Digital product/Tesla یک نتیجه داشت؛ تب Influence بدون checkbox است. آزمون filechooser خودکار Chrome به دلیل مجوز غیرفعال «file URLs» متوقف شد؛ این مجوز تغییر نکرد. خواندن XLSX با parser واقعی و جریان API به‌صورت مستقل آزموده شدند.

تأیید پس از انتشار: بخش روی studio.desartly.info با نشست واقعی مالک باز شد؛ هر شش تب و شمار ۲٬۶۷۷ کارت با شمارش مستقیم D1 تطبیق داشتند. تیک TerraRoots بعد از رفرش باقی ماند و سپس به حالت اولیه برگردانده شد. عرض موبایل ۳۹۰ بدون سرریز بود و فاصلهٔ اضافی هدر مشترک رفع شد؛ Console خطایی نداشت.
