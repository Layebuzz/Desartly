# بررسی نمایش مقاله — ۷ اکتبر ۲۰۲۶

دامنه: مقالهٔ فارسی MyOm و شش ماژول نمودار؛ اصلاح مشترک برای صفحات مقاله. محتوا و وضعیت انتشار مقاله تغییر نکرده است.

| مورد | پیش از اصلاح | نتیجه |
|---|---|---|
| سلسله‌مراتب | عنوان مقاله وزن ۴۰۰؛ تیترهای نمودار بدون عرض مشخص | عنوان ۶۵۰، تیترها ۶۰۰، متن ۴۰۰؛ عرض محدود و شکست متوازن |
| یکپارچگی | هدر و فوتر نمودار ابعاد ناوبری سایت را به ارث می‌بردند | ابعاد مستقل برای ماژول؛ حذف خط و فاصله‌های ناخواسته |
| خوانایی | توضیح نمودار ۱۳٫۸ پیکسل زیر کارت‌ها می‌رفت | فاصلهٔ مثبت ۲۸ دسکتاپ / ۲۴ موبایل برای هر شش نمودار |
| موبایل | قاب اضافی عنوان و کارت‌های آماری دو ستونه | عنوان بدون قاب؛ آمار تک‌ستونه با عدد و برچسب کنار هم |
| واکنش‌گرایی | احتمال تداخل با متن بلند | بررسی ۳۷۵ و ۳۲۰؛ بدون اسکرول افقی، هر شش نمودار بدون تداخل |
| دسترسی | جدول جایگزین داده موجود | حفظ جدول و کنترل بازکردن؛ ممیزی کامل WCAG انجام نشده |

فونت فارسی وزیرمتن حفظ شد. نمودارهای نمونه همچنان برچسب دادهٔ فرضی دارند. تغییر فقط CSS است؛ API، دیتابیس و فایل‌های ذخیره‌شدهٔ PDF دست‌نخورده‌اند.
