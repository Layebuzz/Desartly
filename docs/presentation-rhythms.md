# Case study presentation rhythms

Primary benchmarks reviewed for Divar (29 September 2026):
- [Pentagram — UAnimals](https://www.pentagram.com/work/uanimals): central identity idea, system relationships, contrasting applications and generous editorial space.
- [Pentagram — OffLimits](https://www.pentagram.com/work/offlimits): distinctive characters, a family of expressions, packaging and contextual applications.
- [COLLINS — Mailchimp](https://wearecollins.com/case-studies/mailchimp/): gallery-led opening, changes of scale, juxtaposition of imagery and selective narrative.
- [Studio Dumbar — Wabi](https://studiodumbar.com/work/wabi): a visual language expressed through motion, identity and product touchpoints.

These are structural references, not layouts to copy. Each project needs a different sequence based on what its design actually demonstrates.

## Identity
1. Mark → idea → system pair → one large application → quiet detail → environment.
2. Contextual hero → short brief → character family → contrasting applications → restrained closing image.
3. Editorial opening → typographic interlude → asymmetrical system spread → application pair → full-width finale.

## Campaign and key visuals
1. Campaign world → two equal executions → character interlude → expression family → human context → asset library.
2. One strong master visual → alternating wide / square compositions → concise message → channel applications → final campaign scene.
3. Gallery-first opening → narrative pause → contrasting execution pair → close detail → wide context.

## Product and AI
1. Human context → problem → focused workflow → interaction → reusable system → outcome with evidence.
2. Visual promise → two key decisions → screen sequence → character or illustration language → full product view.
3. Small component → larger composition → actual interface → user context → design system.

## Divar: selected rhythm
The case now opens with a broader mascot-free campaign chapter: a home discovery scene, paired electronics and listing-promotion visuals, then a smaller automotive visual. The AI chapter follows with a clear hero, paired character applications and an expression family. Human context and a category component close the case. All image backgrounds are red; white is reserved for the rounded application-component card. No decorative connecting tracks or slides. The ladder character has two arms with clear shoulder-to-wrist connections.

All presentation imagery is recreated from references. User boards are not displayed directly. No captions, fabricated metrics or invented results. Natural proportions preserve complete subjects. Check desktop and mobile, loaded image height and skeleton removal after every presentation.
